= Sort operator
:page-aliases: {page-version}@typeql-reference::modifiers/sorting.adoc
:test-typeql: linear

The sort operator sorts the input stream based on the variables and their sort order.

NOTE: Sorting requires the server to fetch all results, sort them, then proceed in the pipeline. This may have significant query performance
impact.

== Syntax

The sort direction may be specified explicitly to be ascending (`asc`) or descending (`desc`). The default sort direction when not specified
is ascending.

[,typeql]
----
sort <var> [asc|desc] [ , <var> [asc|desc] ... ];
----

== Example

.Schema for the following examples
[%collapsible]
====
[,typeql]
----
#!test[schema, commit]
include::{page-version}@typeql-reference::example$tql/schema_statements_functions.tql[tags=define-keyword;entities;attributes;relation-friendship]
----
====

Retrieve all friends of a user, sorted by the time they became friends from latest to earliest.

[,typeql]
----
#!test[read]
match
  $user isa user, has name "<name>";
  friendship (friend: $user, friend: $friend),
    has start-date $start;
sort $start desc;
----

Multiple variables may be given. Rows are sorted by the first variable, and ties are broken by each
subsequent one in turn.

[,typeql]
----
#!test[read]
match
  $user isa user, has karma $karma, has username $username;
sort $karma desc, $username asc;
----
