// tag::docker[]
The TypeDB Enterprise image is hosted in our private Docker repository.
Make sure to use `docker login` first to authenticate.

To pull the TypeDB Enterprise Docker image, run:

[source,bash]
----
docker pull typedb/typedb-cluster:latest
----

Use `docker create` to create a new container with the downloaded image.
The container's entrypoint is `typedb server`, so server options are passed as arguments.
A TypeDB Enterprise server listens on port `1729` for gRPC, `8000` for HTTP, and on its clustering address (port `1730`) for replication between servers.
Because the server binds the clustering address itself, run the container on the host network so that the address other servers use is one it can bind.
To ensure that data is preserved even when the container is killed or recreated, mount Docker volumes for both the data directory and the clustering directory:

[source,bash]
----
docker create --name typedb --network host \
    -v $(pwd)/db/data:/opt/typedb-cluster-all-linux-x86_64/server/data \
    -v $(pwd)/db/clustering:/opt/typedb-cluster-all-linux-x86_64/server/clustering \
    typedb/typedb-cluster:latest \
    --diagnostics.deployment-id=my-cluster \
    --server.clustering.id=1 \
    --server.clustering.address=<host-ip>:1730 \
    --server.advertise-address=<host-ip>:1729 \
    --server.http.advertise-address=http://<host-ip>:8000 \
    --initialize.create-cluster=true
----

Replace `<host-ip>` with the host's address at which clients and other servers reach this server.
The image is published for x86_64 and arm64; on arm64 hosts, the paths inside the container start with `/opt/typedb-cluster-all-linux-arm64`.
Use `--initialize.create-cluster=true` only for the first server of a cluster; see xref:{page-version}@home::install/enterprise.adoc#_deploying_manually[Deploying manually] for adding further servers.

[NOTE]
====
The port numbers are configurable. For example, you could configure TypeDB Enterprise to listen on port 80 instead of the default port 1729.
====

==== Start and Stop TypeDB Enterprise in Docker

To start the Docker container, or restart a stopped container:

[source,bash]
----
docker start typedb
----

To check the containers running:

[source,bash]
----
docker ps
----

To stop the Docker container:

[source,bash]
----
docker stop typedb
----
