= TypeDB Enterprise
:page-aliases: {page-version}@manual::install/enterprise.adoc

Run TypeDB Enterprise on your own infrastructure, a self-hosted deployment of TypeDB, fully under your control.
TypeDB Enterprise servers can be xref:{page-version}@reference::typedb-cluster/index.adoc[clustered] for high availability.

TypeDB Enterprise is distributed and installed separately from other editions of TypeDB and requires a <<_license, license>>.

[IMPORTANT]
====
TypeDB is also available as a fully managed cloud service with no installation required at
https://cloud.typedb.com/[cloud.typedb.com,window=_blank].
====

== Connecting

To check whether TypeDB Enterprise is working and interact with it, connect with 
xref:{page-version}@tools::studio.adoc[TypeDB Studio] or xref:{page-version}@tools::console.adoc[TypeDB Console].
Note that xref:{page-version}@tools::console.adoc[TypeDB Console] is also available from your TypeDB Enterprise directory:

[source,bash]
----
./typedb console --address 127.0.0.1:1729 --username admin --tls-disabled
----

To run TypeDB Console from a Docker container, run:

[source,bash]
----
docker exec -ti typedb bash -c '/opt/typedb-cluster-all-linux-x86_64/typedb console --address 127.0.0.1:1729 --username admin --tls-disabled'
----

Console prompts for the password; the default password of the `admin` user is `password`, change it on first use.
Drop `--tls-disabled` once you have enabled xref:{page-version}@maintenance-operation::typedb-in-flight-encryption.adoc[TLS] on the server.
