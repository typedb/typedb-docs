== Create a database

. In the top bar, open the database selector, which shows 'No database selected'.
. Select '+ New Database'.
. Name it `palm_oil` and leave the sample dataset field blank.

The course assumes this database starts empty.

== Run a query

Open the *Query* page, and check that the transaction mode toggle in its toolbar is set to *auto*.
In auto mode, Studio detects whether a query changes the schema, writes data or only reads, opens the matching transaction, and commits it if the query succeeds.
Paste each query from the course into the editor and run it.

The *Schema* page draws the current schema as a graph.
Open it after each chapter to compare it with the ER diagrams in the course.
